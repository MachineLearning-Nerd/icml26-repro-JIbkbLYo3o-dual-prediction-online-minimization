# C3 method

The dual certificate checks the one-element insertion proof cone on the
root-to-leaf chain: charged changes telescope to
`s_d + delta_d - delta_0 <= 2 beta`. Deletions follow by reversing an
insertion, and the triangle inequality joins exactly `|X delta X'|`
single-element changes.

An independent implementation exhausts every integer point in the normalized
proof cone for beta 1 through 11 and confirms the sharp factor is two. This is
a calibration of the symbolic implication, not theorem evidence by finite
extrapolation. The parametric primal family uses exact rational costs.

The negative control substitutes the appendix's undefined `alpha` and must be
rejected. Fixed command and compute are the same as C1.
